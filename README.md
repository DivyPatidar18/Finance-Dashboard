# Ledger-Personal-Finance-Dashboard
<p>Developed a full-featured financial logging system enabling users to track income and expenses with real-time balance calculations .</p>
<p>– Tools & technologies used:HTML5, CSS3 (Custom Properties/Grid), JavaScript (ES6+), LocalStorage API, and Responsive Web Design.</p>
<p>- Implemented a non-volatile data storage system using the Web Storage API (LocalStorage), ensuring user financial
records persist across browser sessions without a backend database.</p>
